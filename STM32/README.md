# STM32 Microcontroller & IoT Experiments

This directory contains ARM Cortex-M3 / Cortex-M4 laboratory experiments and the final IoT mini-project developed 
using **STM32CubeMX**, **Keil MDK-ARM**, and **STM32 HAL Drivers** across the **STM32 Blue Pill (`STM32F103C8T6`)**, 
**NUCLEO-F401RE (`STM32F401RET6`)**, and **NUCLEO-F410RB (`STM32F410RBT6`)** platforms.
